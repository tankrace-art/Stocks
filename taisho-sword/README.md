# 竹林の夜 — 다이쇼 검극 (three.js 3D 검술 액션)

다이쇼 시대풍 일본, 안개 낀 대나무 숲을 무대로 한 저폴리곤 3D 검술 액션 게임입니다.
빌드 도구 없이 ES 모듈 + import map으로 three.js(CDN)를 불러옵니다.

## 실행

**가장 쉬운 방법**: `taisho-sword/play.html`을 더블클릭하면 브라우저에서 바로 실행됩니다(인터넷 연결 필요).
`play.html`은 모든 모듈을 하나로 합친 단일 파일 빌드이며 `node build-standalone.mjs`로 다시 생성합니다.

개발용(모듈 분리 상태)으로 실행하려면 정적 서버가 필요합니다.

```bash
# 리포지토리 루트에서
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000/taisho-sword/ 접속
```

**아이패드/모바일**: 터치 기기를 자동 감지해 왼쪽 화면 가상 조이스틱(이동), 오른쪽 화면 드래그(시점)·탭(베기), 우하단 斬·強·閃·秘剣 버튼으로 조작합니다. 가로 화면 권장.

## 조작

| 입력 | 동작 |
| --- | --- |
| W A S D | 이동 (카메라 기준) |
| 마우스 | 시점 회전 (포인터 락) |
| Shift | 대시 — 짧은 무적, 공격 캔슬 가능 |
| 좌클릭 | 기본 3연타 (가로 → 가로 → 내려베기) |
| 우클릭 | 강공격 (긴 준비, 큰 넉백) |
| F / Space | 秘剣・波焔 — 기술 게이지 100%일 때 발동 |
| Esc | 일시정지 |

## 시나리오

한 번 고른 검사로 다섯 장을 이어 갑니다. 진행(장·동료·레벨·장비·금화)은 캐릭터별로 저장되며 타이틀의 "이어하기"로 계속합니다.

1. 대숲의 밤 — 마을을 덮친 첫 요괴 흑귀
2. 폐사의 안개 — 검사단 합류, 대검사와의 만남, 하급 장군 백면귀 (동료 1명 합류)
3. 설산의 사당 — 하급 장군의 우두머리 빙귀
4. 붉은 달의 성 — 상급 장군 적안귀 (동료 2명째 합류)
5. 무한 미궁성 — 요괴의 왕 귀왕, 최종전

동료 검사는 AI로 함께 싸우며, 쓰러지면 잠시 뒤 일어납니다. (온라인 협동은 서버가 필요해 미지원)

## 캐릭터·성장·아이템

- **검사 5명** 중 선택: 유키(균형) · 라이(속도) · 쿠마(중량) · 히노(공격) · 카제(기술). 캐릭터마다 능력치와 비검(필살기) 연출이 다릅니다.
- **경험치·레벨**: 요괴를 베고 파도를 돌파하면 경험치를 얻고, 레벨이 오를 때마다 스킬 포인트 1을 받습니다.
- **스킬 트리**(Tab 또는 장비·스킬 버튼): 검술 / 체술 / 비검 3계열 × 3단계. 이전 단계를 배워야 다음 단계를 열 수 있습니다.
- **아이템**: 요괴가 금화·회복약·장비(칼·머리·가슴·허리·팔·다리·부적 7부위)를 떨어뜨립니다. 장비 메뉴의 종이인형에서 부위별로 장착합니다.
- **상점**(메뉴 → 상점): 금화로 회복약과 등급별 장비를 사고, 가방의 장비를 팝니다. 진열은 장이 바뀔 때 갱신됩니다. 등급은 일반 / 레어 / 히든 / 유니크이며 등급이 높을수록 능력치가 많고 강합니다. 가까이 가면 자동으로 줍고, 장비 메뉴에서 장착합니다. 회복약은 Q(터치: 약 버튼).
- 레벨·스킬·장비·회복약은 캐릭터별로 브라우저에 저장되어 다음 판에도 이어집니다.
- **BGM**은 직접 작곡한 주제곡(A단조 8마디 진행, 현악 패드·피리 선율·고토·태고)을 Web Audio로 실시간 연주합니다. 보스전에서 템포와 타악이 강해지고 새벽엔 잔잔해집니다. M 또는 소리 버튼으로 끄기.
- **기술 연출**: 캐릭터마다 유파의 형(型) 이름이 연타 마무리·강공격·비검에 붓글씨처럼 표시되고, 물결·번개·지진·불꽃·바람 테마 파티클이 검격마다 나갑니다.

## 규칙

- **밤에만 요괴가 활동**합니다. 하단 진행 바가 달(☾)에서 해(☀)로 차오릅니다.
- 웨이브 3개를 지나면 보스 **黒鬼**가 등장합니다. 보스는 체력 50% 이하에서 2페이즈(귀화 고리 발사)로 전환됩니다.
- 보스를 쓰러뜨리거나 밤이 끝나면 **새벽**이 오고, 남은 요괴는 전부 재가 되어 소멸합니다.
  - 보스를 베고 새벽을 맞으면 `夜明け` (승리), 밤을 버텨내기만 하면 `夜明け` (생존) 엔딩.
- 기술 게이지는 타격 시 차오릅니다. 투사체(귀화)를 베어내면 소량 충전됩니다.
- 콤보 카운터는 약 2.4초간 타격이 없거나 피격 시 초기화됩니다.

## 파일 구조

```
taisho-sword/
├─ index.html   # 캔버스, UI 컨테이너, three.js import map
├─ style.css    # HUD/화면 스타일 (다이쇼풍 명조 타이포)
├─ main.js      # 초기화, 입력, 게임 루프, 상태 전환, 밤→새벽 규칙
├─ player.js    # 검사 캐릭터: 프리미티브 모델, 카메라, 대시, 3연타/강공격/특수기, 검기 파동
├─ enemy.js     # 요괴: 小鬼(근접), 鬼火(원거리), 黒鬼(보스), 투사체, 웨이브/새벽 소멸 관리
├─ stage.js     # 대나무 숲(인스턴싱), 안개, 석등/도리이/제등, 달·별·반딧불, 밤→새벽 조명 전환
├─ ui.js        # 체력바, 기술 게이지, 콤보, 보스 체력, 밤 진행, 메시지, 타이틀/결과 화면
├─ touch.js     # 아이패드/모바일 터치 컨트롤 (가상 조이스틱, 시점 드래그, 액션 버튼)
├─ characters.js # 검사 5명 정의(외형·기술명), 스킬 트리, 경험치/레벨/인벤토리/장 진행 저장
├─ scenario.js  # 시나리오 5장(이야기·파도·보스)과 무대 테마
├─ ally.js      # 동료 검사 AI
├─ items.js     # 회복약·등급별 장비 생성, 능력치 합산
├─ audio.js     # Web Audio 절차 생성 BGM(고토·피리·태고)과 효과음
├─ play.html    # 단일 파일 빌드 (더블클릭 실행용)
├─ build-standalone.mjs  # play.html 생성 스크립트
├─ effects.js   # 파티클(물결/불꽃), 검격 궤적, 충격파, 카메라 흔들림
└─ util.js      # 보간/이징 헬퍼
```

## 확장 포인트

- 캐릭터는 모두 프리미티브 조합입니다. `player.js`의 `buildModel()` / `enemy.js`의 `_build()`를 GLTF 로더로 교체하면 로우폴리 모델로 바꿀 수 있습니다.
- 공격 데이터는 `player.js` 상단 `ATTACKS` 테이블에 모여 있어 판정/이펙트/애니메이션 포즈를 한 곳에서 조정할 수 있습니다.
- 웨이브 구성은 `enemy.js`의 `WAVES` 배열에서 수정합니다.
