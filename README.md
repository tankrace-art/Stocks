# DART 재무분석 투자도구

DART OpenAPI를 활용한 **투자 의사결정용** 재무분석 도구입니다.

## 핵심 기능

### 1. 재무제표 연도별 크로스 비교
- 재무상태표, 손익계산서, 현금흐름표를 **연도별 열(column)**로 정리
- 한눈에 5개년 추이 비교 가능

### 2. 핵심 투자지표 자동 계산
| 구분 | 지표 |
|------|------|
| **수익성** | 영업이익률, 순이익률, ROE, ROA |
| **안정성** | 부채비율, 유동비율, 자기자본비율 |
| **성장성** | 매출성장률, 영업이익성장률, 자산성장률 |
| **현금흐름** | FCF(잉여현금흐름), 영업CF/매출액 |

### 3. 사업보고서 핵심 데이터 추출
- 매출 구성 및 실적
- 주요 제품/서비스, 가격
- 생산능력, 가동률, 설비 현황
- 수주 현황 / 잔고
- 연구개발 투자 현황
- 시장점유율

### 4. 엑셀 출력
- 투자지표 요약 시트 (첫 번째 시트)
- 재무제표 크로스 비교 시트
- 연도별 사업내용 시트
- 자동 스타일링 (헤더, 섹션 구분, 열 너비)

## 사전 준비

### 1. DART API 키 발급
[DART OpenAPI](https://opendart.fss.or.kr)에서 회원가입 후 인증키를 발급받으세요.

### 2. 설치
```bash
pip install -r requirements.txt
```

### 3. API 키 설정
```bash
cp .env.example .env
# .env 파일을 편집하여 DART_API_KEY 입력
```

## 사용법

### GUI (더블클릭 실행)
```bash
python run_gui.py
```
또는 `재무분석_실행.bat` 더블클릭

### CLI
```bash
# 5개년 투자분석
python -m dart_scraper.main -c "삼성전자" -p "2020-2024"

# 사업내용 제외 (재무제표 + 투자지표만)
python -m dart_scraper.main -c "SK하이닉스" -p "2022-2024" --no-business

# 개별재무제표
python -m dart_scraper.main -c "현대자동차" -p "2023" --fs 개별
```

## 기간 입력 형식

| 형식 | 설명 | 예시 |
|------|------|------|
| `YYYY` | 단일 연도 | `"2024"` |
| `YYYY-YYYY` | 연도 범위 | `"2020-2024"` |

## 참고

- DART OpenAPI는 2015년 이후 데이터를 제공합니다
- 연결재무제표 조회 실패 시 자동으로 개별재무제표로 재시도합니다
- API 호출 간 0.5초 간격으로 rate limit을 준수합니다
