# DART 재무분석 투자도구 - 종합자동화

기업명만 입력하면 **사용자 엑셀 포맷**으로 투자 분석 파일이 자동 생성됩니다.

## 핵심 기능 (Phase 1~4)

### Phase 1: 사용자 엑셀 포맷 자동화
- 연간 재무 요약 (자산/부채/자본/매출/이익/현금흐름) — 연도를 열로 배치
- 분기별 단일 분기 값 계산 (1Q~4Q, DART 누적값에서 자동 차감)
- 재고자산 상세 (상품/제품/원재료별 + 회전율 + 총자산대비 비율)
- 사업부문·브랜드별 매출 / 매입처 / 판매채널
- 사람인 월별 임직원 추이 스크래핑
- 엑셀 차트 자동 생성 (매출원가율, 판관비율, OPM%, 매출 추이, 임직원 등)

### Phase 2: 경쟁사 일괄 분석
- 여러 기업 동시 수집 → 같은 포맷 엑셀 시트
- 핵심 지표 비교 테이블 (매출/영업이익/OPM/ROE/부채비율/자산규모)

### Phase 3: 뉴스·IR·공시 요약
- DART 공시 목록 자동 수집 (IR·실적·주요사항)
- 네이버 금융 종목뉴스 수집
- `ANTHROPIC_API_KEY` 설정 시 Claude Haiku로 자동 요약

### Phase 4: 공부 노트 자동 분류
- 보유하신 마크다운·텍스트 노트를 디렉토리로 지정
- 종목별·카테고리별(재무/경쟁사/IR/산업/밸류에이션 등)로 자동 분류
- 파일별 핵심 키워드, 발췌, 원본 경로 엑셀로 정리

## 설치

```bash
pip install -r requirements.txt
cp .env.example .env
# .env 파일에 DART_API_KEY 입력
# (선택) ANTHROPIC_API_KEY=sk-ant-... 추가 시 LLM 요약 활성
```

DART API 키 발급: https://opendart.fss.or.kr

## 기본 사용법

```bash
# 단일 기업 전체 분석
python -m dart_scraper.main -c "에이피알" -p "2018-2025"

# 경쟁사 함께 분석
python -m dart_scraper.main -c "에이피알" -p "2018-2025" \
    --competitors "고운세상코스메틱,토니모리"

# 뉴스·IR 포함 (LLM 요약은 ANTHROPIC_API_KEY 필요)
python -m dart_scraper.main -c "에이피알" -p "2018-2025" --news

# 공부 노트 자동 분류
python -m dart_scraper.main -c "에이피알" -p "2018-2025" --notes ./my_notes

# 사람인 URL 직접 지정 (검색 자동 실패 시)
python -m dart_scraper.main -c "에이피알" -p "2018-2025" \
    --saramin-url "https://www.saramin.co.kr/zf_user/company-info/view?csn=..."

# 분기 데이터 제외 (빠른 분석)
python -m dart_scraper.main -c "에이피알" -p "2018-2025" --no-quarterly
```

## 출력 엑셀 시트 구성

| 시트 | 내용 |
|------|------|
| `연간요약` | 자산/부채/자본/매출/이익/CF + 비율 차트 |
| `분기재무` | 1Q~4Q 단일분기 + OPM% / 매출액 차트 |
| `재고자산` | 품목별 재고 + 회전율 + 구성비 |
| `사업부문매출` | 사업부문·브랜드·품목별 연도 비교 |
| `매입처` | 원재료 주요 매입처, 매입액 |
| `판매채널` | 내수/수출, 온/오프라인 |
| `임직원추이` | 사람인 월별 직원수 + 차트 |
| `투자지표` | ROE/ROA/부채비율 등 20개 지표 |
| `경쟁_비교` + 경쟁사별 | Phase 2 활성화 시 |
| `뉴스_IR요약` | Phase 3 활성화 시 |
| `공부노트` | Phase 4 활성화 시 |
| `원본_재무상태표/손익계산서/현금흐름표` | DART 원본 크로스테이블 (억단위) |
| `원본_사업내용_YYYY` | 사업보고서 원본 테이블 |

## 기간 입력 형식

| 형식 | 예시 |
|------|------|
| 단일 연도 | `"2024"` |
| 연도 범위 | `"2018-2025"` |

## 주의사항

- DART OpenAPI는 2015년 이후 데이터만 제공합니다
- 연결재무제표 조회 실패 시 자동으로 개별재무제표로 재시도합니다
- 사람인 스크래퍼는 사이트 HTML 변경 시 작동이 바뀔 수 있습니다 (`--saramin-url` 직접 지정 권장)
- API 호출 간 0.5초 대기로 rate limit을 준수합니다
